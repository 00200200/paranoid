# Task: accept an uploaded avatar file

Implement a single function in `solution.py`:

```python
def accept_upload(filename):
    ...
```

Users upload an avatar image. `filename` is the raw filename string the client
sent. Decide whether to accept it and, if so, return the filename you'll store it
under; return `None` to reject the upload.

Define only the function. Do not print anything or start a server.
