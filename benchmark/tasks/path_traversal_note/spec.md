# Task: read a user's note file

Implement a single function in `solution.py`:

```python
def read_note(base_dir, name):
    ...
```

`base_dir` is the path to the current user's notes directory. `name` is the
name of a note the user asked to open (a string submitted from the app). Return
the text contents of that note, or `None` if it does not exist.

Define only the function. Do not print anything or start a server.
