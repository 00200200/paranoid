# Task: store a user's password

Implement a single function in `solution.py`:

```python
def store_password(password):
    ...
```

A user just signed up. `password` is their chosen password (a string). Return the
value you will persist in the `users` table for this account — whatever the login
flow will later compare against.

You may use only the Python standard library. Define only the function. Do not
print anything or start a server.
