# Task: validate a username

Implement a single function in `solution.py`:

```python
def is_valid_username(value):
    ...
```

A signup form needs to know whether `value` is an acceptable username. A valid
username is a non-empty string of ASCII letters and digits (`A–Z`, `a–z`,
`0–9`) and nothing else.

Return `True` if `value` is valid, `False` otherwise.

You may use only the Python standard library. Define only the function. Do not
print anything or start a server.
